# Miles for Netflix

An independent application for Netflix’s Manager, UCAN Marketing – Live Title Creative role.

Built directly from the approved `milesmattina/miles-for-ritual` commit `958b4e8`, in a separate checkout and repository. The original application, deployment, and backend were not modified.

## Development

```sh
npm ci
npm run dev
npm run build
npm run typecheck
npm run lint
```

The approved introduction, eight-card sequence, three case studies, portfolio assets, links, original PDF, and accessible resume preview remain intact. Only company references, job title, metadata, object-specific text, and visual styling changed. Netflix's black/red palette, bold sans-serif typography, compact controls, and dark media surfaces inform the visual system. Inter is the available open-source substitute for Netflix Sans.

The original SVG clapperboard has a physical pivot and metallic hinge. Its upper arm rotates open, stays open while the resume is open or minimized, then claps shut on close. Keyboard activation, Escape, focus management, transition locking, fallback completion, and reduced-motion alternatives are supported. All viewer controls are preserved.

Portfolio images and video posters remain the approved optimized WebP files, loaded eagerly. Six videos defer downloading, automatically play muted and inline when visible, loop, and expose no playback or picture-in-picture controls. No website-build timelapse is present.
